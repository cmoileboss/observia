# Observia

## Prérequis

- Python 3.x
- Git

## Installation

### 1. Cloner le dépôt GIT

```bash
git clone https://github.com/cmoileboss/observia.git
cd observia
```

### 2. Créer et activer l'environnement virtuel

```bash
python -m venv .venv
```

**Windows (PowerShell) :**
```powershell
.\.venv\Scripts\Activate.ps1
```

**Linux / macOS :**
```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```
